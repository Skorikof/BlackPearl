# BlackPearl

**BlackPearl** — настольное приложение для загрузки музыки и другого медиаконтента. Проект написан на Python, графический интерфейс построен на PySide6.

Приложение использует систему провайдеров: каждый провайдер отвечает за взаимодействие с определённым источником, а общий интерфейс позволяет подключать новые источники без переноса их логики в GUI.

## Возможности

### Яндекс Музыка

- Получение информации об отдельном треке.
- Загрузка списка композиций из альбома.
- Загрузка треков из плейлистов:
  - по обычной ссылке пользователя;
  - по ссылке с UUID.
- Получение списка треков исполнителя.
- Отображение списка композиций в таблице.
- Выбор отдельных композиций, выбор всех или снятие выбора.
- Последовательная загрузка отмеченных треков.
- Выбор целевого битрейта MP3: 128, 192 или 320 кбит/с. Провайдер выбирает доступный вариант, не превышающий выбранное значение; если такого варианта нет, используется минимальный доступный.
- Запись метаданных MP3: название, исполнитель, альбом, год выпуска и обложка (если данные доступны).

### Другие источники

- Подключён провайдер на базе [yt-dlp](https://github.com/yt-dlp/yt-dlp). Фактическая поддержка конкретного сайта зависит от возможностей yt-dlp.
- Для загрузок через yt-dlp отображается прогресс, поддерживается отмена.

### Интерфейс и загрузки

- Графический интерфейс на PySide6 с формой, созданной в Qt Designer.
- Таблица композиций остаётся на экране; одиночный трек отображается одной строкой, коллекция — списком треков.
- Получение информации, загрузка списка коллекции и скачивание выполняются в фоновых потоках, чтобы не блокировать интерфейс.
- Загрузки из коллекции выполняются последовательно.

## Текущие ограничения

- Для работы с Яндекс Музыкой требуется действующий токен авторизации.
- Яндекс Музыка не предоставляет в используемом сценарии загрузки потоковый прогресс: индикатор обновляется после завершения загрузки трека. Отмена во время самой операции загрузки не прерывает сетевой запрос немедленно; результат удаляется, если отмена была запрошена до окончания операции.
- Настройка битрейта MP3 применяется к провайдеру Яндекс Музыки. Провайдер yt-dlp пока не использует выбранное в интерфейсе значение битрейта и не выполняет отдельную настройку извлечения аудио.
- Проект находится в активной разработке; интерфейс и набор поддерживаемых источников будут расширяться.

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/Skorikof/BlackPearl.git
cd BlackPearl
```

Установите зависимости, включая зависимости для разработки и тестирования:

```bash
uv sync --extra dev
```

`uv` создаст виртуальное окружение проекта и установит зависимости из `pyproject.toml`.

## Настройка Яндекс Музыки

1. В корне проекта создайте файл `.env` (можно скопировать `.env.example`).
2. Укажите в нём свой токен:

```env
YANDEX_MUSIC_TOKEN=your_token_here
```

Замените `your_token_here` на действующий токен Яндекс Музыки.

> Не публикуйте токен и не добавляйте файл `.env` в Git. В репозитории должен находиться только `.env.example` без реальных секретов.

## Запуск

Из корневой директории проекта выполните:

```bash
uv run python -m blackpearl
```

## Использование

### Отдельный трек

1. Запустите приложение.
2. Вставьте ссылку на трек в поле ввода.
3. Нажмите кнопку проверки ссылки и дождитесь получения информации.
4. Выберите качество MP3.
5. Нажмите кнопку загрузки и укажите папку назначения.

### Альбом, плейлист или список треков исполнителя

1. Вставьте ссылку на альбом, плейлист или страницу треков исполнителя Яндекс Музыки.
2. Нажмите кнопку проверки ссылки.
3. Дождитесь появления композиций в таблице.
4. Отметьте нужные треки. По умолчанию отмечены все найденные композиции; кнопками рядом с таблицей можно выбрать все или снять выбор.
5. Нажмите кнопку загрузки и укажите папку назначения.

Отмеченные композиции будут загружаться по очереди. Общий индикатор показывает продвижение очереди; особенности отображения прогресса Яндекс Музыки описаны в разделе «Текущие ограничения».

## Архитектура

### Providers

Провайдеры реализуют общий интерфейс `MediaProvider`:

- `can_handle()` — проверяет, может ли провайдер обработать ссылку;
- `get_info()` — получает информацию о медиа;
- `download()` — загружает медиа.

`ProviderRegistry` хранит зарегистрированные провайдеры и выбирает подходящий для ссылки.

### Services

Сервисный слой выполняет длительные операции отдельно от GUI:

- `InfoWorker` — получение информации об отдельном медиа;
- `CollectionWorker` — получение списка треков коллекции;
- `DownloadWorker` — загрузка одного элемента;
- `DownloadManager` — управление последовательной очередью загрузок, сигналами прогресса, завершения, ошибки и отмены.

### UI

- `main_window.py` связывает форму, провайдеры и сервисный слой.
- `ui/main_ui.ui` — исходная форма Qt Designer.
- `ui_py/main_win.py` — Python-код, сгенерированный из `.ui`-формы.
