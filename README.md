# BlackPearl

**BlackPearl** — универсальный загрузчик медиа с графическим интерфейсом на Python и PySide6.

Проект построен на модульной архитектуре с поддержкой различных источников через отдельные провайдеры.

## Возможности

### Реализовано

- Графический интерфейс на PySide6.
- Поддержка Яндекс Музыки:
  - одиночные треки;
  - альбомы;
  - плейлисты.
- Получение информации о медиа.
- Выбор отдельных композиций из альбомов и плейлистов.
- Последовательная загрузка выбранных треков.
- Выбор качества MP3: 128, 192 и 320 кбит/с.
- Сохранение метаданных аудиофайлов:
  - название композиции;
  - исполнитель;
  - альбом;
  - год;
  - обложка.
- Отображение прогресса загрузки.
- Возможность отмены загрузки.
- Фоновая обработка операций, чтобы интерфейс оставался отзывчивым.

### В разработке

- Улучшение графического интерфейса.
- Расширение поддержки источников.
- Дальнейшее развитие системы загрузок.

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/Skorikof/BlackPearl.git
cd BlackPearl
```

### 2. Установка зависимостей

```bash
uv sync --extra dev
```

Команда создаст виртуальное окружение и установит необходимые зависимости проекта.

## Настройка Яндекс Музыки

Для работы с Яндекс Музыкой необходимо настроить токен авторизации.

### 1. Создание файла окружения

В корне проекта создай файл `.env`:

```env
YANDEX_MUSIC_TOKEN=your_token_here
```

Замени `your_token_here` на свой токен.

## Запуск

Из корневой директории проекта:

```bash
uv run python -m blackpearl
```

После запуска откроется графический интерфейс BlackPearl.

## Использование

### Загрузка одиночного трека

1. Запусти BlackPearl.
2. Вставь ссылку на поддерживаемый источник.
3. Нажми «Проверить источник».
4. Дождись получения информации.
5. Выбери качество MP3.
6. Нажми «Скачать».
7. Укажи папку для сохранения.

### Загрузка альбома или плейлиста

1. Вставь ссылку на альбом или плейлист Яндекс Музыки.
2. Нажми «Проверить источник».
3. Дождись загрузки списка композиций.
4. Выбери нужные треки или воспользуйся кнопками выбора.
5. Нажми «Скачать».
6. Укажи папку для сохранения.

Выбранные композиции загружаются последовательно. Прогресс отображается в главном окне.

## Архитектура

### Providers

Провайдеры отвечают за взаимодействие с конкретными источниками медиа.

Общий интерфейс `MediaProvider` определяет основные операции:

- проверка поддержки ссылки;
- получение информации о медиа;
- загрузка медиа.

`ProviderRegistry` определяет подходящий провайдер для переданной ссылки.

### Services

Сервисный слой отвечает за выполнение операций вне основного интерфейса.

- `InfoWorker` — получение информации о медиа в отдельном потоке.
- `CollectionWorker` — получение списка треков коллекции.
- `DownloadWorker` — выполнение загрузки.
- `DownloadManager` — управление загрузками и их жизненным циклом.

### UI

Пользовательский интерфейс построен на PySide6.

Основное окно взаимодействует с провайдерами и сервисами, отображает информацию, управляет выбором треков и показывает состояние загрузки.
